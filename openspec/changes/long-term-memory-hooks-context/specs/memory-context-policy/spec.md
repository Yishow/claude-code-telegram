## ADDED Requirements

### Requirement: 記憶範圍隔離政策
系統 SHALL 以工作目錄作為硬性範圍邊界，記憶召回 MUST 僅來自當前目錄範圍，避免跨專案污染。

#### Scenario: 切換目錄後召回隔離
- **WHEN** 使用者從目錄 A 切換到目錄 B 並發送訊息
- **THEN** 系統 MUST 不得召回目錄 A 的記憶項目

### Requirement: 記憶保留與淘汰政策
系統 MUST 實作可設定的保留期限與上限策略，對過期或低優先記憶進行淘汰，並保留淘汰原因。

#### Scenario: 超過保留期限時淘汰
- **WHEN** 記憶項目超過設定 TTL 或命中淘汰條件
- **THEN** 系統 MUST 將該項目標記為不可召回或移除，並記錄淘汰原因

### Requirement: 記憶衝突處理政策
系統 MUST 在新舊記憶衝突時保留可追溯資訊，不得無痕覆蓋既有記憶。

#### Scenario: 新記憶與既有決策矛盾
- **WHEN** 新萃取的「決策」與既有同類記憶內容衝突
- **THEN** 系統 MUST 保留衝突狀態與來源引用，供後續人工或增強層判定

### Requirement: AI 模組設定生效範圍政策
系統 SHALL 以「使用者 + 聊天室 + 話題（若有）」作為 AI 模組設定作用範圍，避免不同會話互相覆蓋。

#### Scenario: 同一使用者在不同話題切換設定
- **WHEN** 使用者在話題 A 關閉 `reranker`，並在話題 B 保持開啟
- **THEN** 系統 MUST 在兩個話題套用各自設定，不得互相覆蓋
